Anything Anywhere — Master Build Prompt

Build a production-quality delivery platform called Anything Anywhere.

The product slogan is:

Anything. Anywhere. Delivered.

Secondary brand message:

No Tips. Best Service.

The initial launch market is Raleigh, North Carolina, USA, but the architecture must allow expansion to other US cities later.

This is NOT a simple prototype. Build a working full-stack application with a shared backend and database that will eventually power THREE coordinated interfaces:

1. Customer App
2. Driver App
3. Admin Dashboard

For this first stage, build the complete shared backend architecture and the Customer App.

TECHNOLOGY

Use a modern architecture that works well on Replit.

Preferred stack:

* TypeScript
* React Native + Expo for iPhone and Android
* Expo Web support for browser
* Node.js/TypeScript backend
* PostgreSQL database using Replit Database
* Replit Auth or a secure authentication solution supported by Replit
* REST API or a clean typed API layer
* WebSockets or another reliable real-time mechanism for delivery updates
* Secure environment variables using Replit Secrets

Do NOT hard-code API keys, passwords, payment secrets, database URLs, or private credentials.

Structure the repository clearly so Customer, Driver, Admin and backend share models/types where appropriate.

Suggested structure:

/apps/customer
/apps/driver
/apps/admin
/server
/shared
/database

If a better monorepo structure is appropriate, use it.

CRITICAL REQUIREMENT

Customer App, Driver App and Admin Dashboard must all use the SAME backend, SAME order records and SAME source of truth.

Do not create fake independent databases for each app.

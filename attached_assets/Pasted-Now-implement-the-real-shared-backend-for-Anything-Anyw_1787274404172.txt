### Security

Implement Supabase Row Level Security\.

Customer:

- sees only their own account and deliveries\.

Driver:

- sees only available offers they are authorized to see\.
- sees full delivery information only after appropriate assignment\.
- can update only permitted delivery fields\.
- can update their own location\.

Admin:

- role\-protected access\.

Never rely only on hiding buttons in the frontend for security\.

Validate authorization on the server/database layer\.

Create database migrations and useful seed/demo data separately from production data\.
